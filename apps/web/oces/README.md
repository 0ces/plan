# apps/web/oces

Web code for this fork's own features (pages, components, MobX stores, services).
Import it as `@oces/...` (alias in `apps/web/tsconfig.json`, picked up by `vite-tsconfig-paths`).
New pages register through `app/routes/extended.ts`. See `docs/fork/PLAN.md`.
New `.ts`/`.tsx` files need the AGPL header used across the repo.
